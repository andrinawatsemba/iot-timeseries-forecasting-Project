## IoT Time Series Forecasting Project
This project applies time series analysis techniques to a simulated Internet of Things (IoT) dataset. The dataset contains hourly sensor readings from a single manufacturing machine (MCH-001) over a 21-day period, capturing variables such as machine temperature, power consumption, vibration level, pressure, humidity, and production output.
#### Part A:
Data exploration, decomposition, preprocessing, stationarity testing, ACF/PACF analysis, differencing, smoothing, and model selection (ARIMA vs. SARIMA / Exponential Smoothing)
#### Part B:
Out-of-sample forecasting, model evaluation (MAE, RMSE, MAPE), and critical reflection on model limitations
#### Tools & Libraries:
Python, pandas, statsmodels, matplotlib, scikit-learn
